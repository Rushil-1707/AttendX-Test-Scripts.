
# AttendX Test Scripts

## Project Description
Basic automated tests for a student attendance application.

## Test Scripts
1. test_login.py - Valid, invalid and empty login tests.
2. test_attendance.py - Present, absent and empty student ID tests.

## Technologies Used
- Python
- Pytest
- Git
- GitHub
- Visual Studio Code

## How to Run
Install pytest using:

pip install pytest

Run the tests using:

pytest -v
